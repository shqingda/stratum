# 真机走查：问题清单

2026-11-16，`scripts/demo.sh` 起的演示环境（Talos Dev，提交 92fbe5f），窗口 1200×780，浅色为主、深色抽查。设计稿用 `design/fidelity/shoot.sh` 渲染成 `design/fidelity/out/design-1.png` … `design-7.png`，真机截图在同目录的 `app-*.jpg`（这些图不进仓库）。

只记录，不修。按影响排序：先是用不了或会误导的，再是和设计稿不一致的。

## 一、行为问题

1. **窗口不在最前时，内核来的更新不重画。** 切换会话后一直停在「Syncing…」，侧栏选中项还在旧会话上；点「允许」后卡片停在「回答中」，「等了 25 秒」不再走；轮次早已结束，界面仍是运行中。滚动不触发重画，点一下窗口任意处才刷新。截图：`app-syncing-stuck.jpg`、`app-approval-answering.jpg`。原因未确认：可能是窗口被遮挡时 display link 停了，更新只排进队列不请求帧。复现：让 Talos 被别的窗口完全挡住，在侧栏点另一个会话。
2. **侧栏行的标题和状态错位（同一原因的另一种表现）。** 同一帧里「需要你」组显示「New Session」、没有徽标，calc 组却显示「跑一遍测试」带 Approval 徽标，而这个会话实际在 notes。点一下窗口后恢复正确。截图：`app-approval-sidebar.jpg`。
3. **改动卡片的行号错。** 转录里 add.go 的 diff 卡片把第 6 行标成 1；右侧 Review 面板同一处标 6。截图：`app-diff-line-numbers.jpg`、`app-review-1200.jpg`。
4. **改文件的审批卡显示绝对路径，没有 diff 预览。** 卡片里是两行长的 `/private/tmp/…/calc/add.go`，看不出要改什么；同一轮里命令审批卡用的是缩短的路径。设计稿没有画改文件的审批卡。截图：`app-edit-approval.jpg`。
5. **窄窗口下顶栏和卡片被挤坏。** 1200 宽打开 Review 面板后：会话标题只剩「…」、文件夹和分支挤在一起，「Changed 1 file」截成「Change…」。设计稿主窗口按 1440 画，没有给出窄窗口的规则（先收侧栏，还是先缩面板）。截图：`app-review-1200.jpg`。
6. **代码块上方多一空行。** 回复里的输出块，复制按钮占了第一行，内容从第二行开始；回复自己的复制按钮单独占一行。截图：`app-turn-done.jpg`。
7. **演示剧本和仓库对不上。** notes 仓库里没有 Go 代码，剧本仍回答「TestAdd 失败… add.go 里写成了 a − b」。只影响演示。
8. **菜单栏没有应用自己的命令。** 只有 Talos Dev / Edit / View / Window；新会话、⌘K、⌘F、⌘J 都不在菜单里，View 里是 Reload、Force Reload、Toggle Developer Tools 这些网页应用的默认项。
9. **「关于」的版本号写了两遍，且是伪版本。** 标题下一遍、表格里一遍，都是 `v0.0.0-2026…-92fbe5fdf472+dirty`。应用菜单里已有 `updater` 提供的「Check for Updates…」（`cmd/talos/main.go:78`），关于页可以接上它，而不是不做。截图：`app-settings-about.jpg`。

## 二、和设计稿不一致

### 主窗口（design-1、design-2）

- 用户消息：设计稿是左侧竖线引用块、下面挂附件；真机是右侧气泡。
- 侧栏导航：设计稿有「新会话 ⌘N」「定时任务」「技能与 MCP」三行；真机只剩「技能与 MCP」，新会话只在右上角图标。
- 推理强度标签：设计稿写「中」，真机写「Default」。
- 改动卡片：设计稿每个文件一张卡片，带「撤销」；真机在轮次结束后合成「Changed 1 file」一行加 Undo All。两种都有，但运行中设计稿已经显示文件卡片。
- Review 面板：设计稿页签是「变更 / 终端 / 计划 / 文件」和右上「…」；真机没有「文件」页签和「…」。

### 新会话（design-3）

- 输入框里设计稿有文件夹和分支选择（calc ▾、main ▾），占位文字是「描述任务，用 @ 引用文件，/ 调用技能」；真机没有这两个选择，占位是「Ask Talos to do something」。截图：`app-new-session.jpg`。

### ⌘K（design-4）

- 设计稿底栏有「⌘↵ 在新窗口打开」；真机没有多窗口，这一项没有。其余（会话、操作、文件三组，选中行的 ↵）一致。截图：`app-palette.jpg`。

### 设置（design-5、`design/settings.html`）

- 页面标题：设计稿在内容区顶部用大标题加一句说明（「账号与模型」「凭据存在钥匙串里…」）；真机只在顶栏写小字。
- 分页：设计稿是「账号与模型」合一页、「权限与沙箱」；真机拆成 Accounts、Models、Permissions。设计稿的「关于」在侧栏底部（「Talos 0.2.0 · 检查更新」），真机是单独一页。
- 模型分工：设计稿每行带副标题（「你直接对话的那个」）和各自的推理强度选择；真机只有一个全局推理强度。截图：`app-settings-models.jpg`。
- 新会话默认权限：设计稿是三张并排卡片；真机是单选列表。截图：`app-settings-permissions.jpg`。
- 账号行：设计稿有额度和重置时间；真机没有（计划里写明：没有数据源，不显示）。

### 登录、终端与计划（design-6、design-7）

- 本次没有走到：演示环境已有账号，不出登录页；终端和计划页签没有点开。下次走查补上。
